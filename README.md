# メガドライブ ゲームカタログ

Python標準ライブラリのTkinterとSQLiteで動作する、ローカル保存型のゲームカタログです。

## 起動方法

Python 3 がインストールされた環境で、このフォルダから実行します。

```powershell
python game_catalog.py
```

初回起動時に `games.db` が自動作成されます。

## 使い方

- 「ゲームを追加」でタイトル、英語タイトル、発売元、発売年、地域・型番、ジャンル、読者レース順位・全投票平均スコア、メモを登録
- ジャンルは A・ACT、A・RPG、ACT、ADV、ETC、PIN、PUZ、QIZ、RAC、RPG、SHT、SHT/SLG、SLG、SPT、TAB、VCS、VIC から選択
- 読者レース順位は1以上の整数、全投票平均スコアは `9`、`9.42`、`6.2934` の形式（整数または小数点以下1〜4桁、最大 `9.9999`）で入力
- 編集画面の「タイトル画像」から画像ファイルを選ぶと、検索結果を「画像」に切り替えたときカード内に表示
- 画像表示はPillowがあればPNG/JPEG/GIF/BMPに対応。Pillowがない場合はTk標準対応のPNG/GIFを表示
- 一覧の作品をダブルクリックするか「編集」で情報を更新
- 検索欄でタイトルや発売元などを絞り込み
- 検索欄はタイトル、英語タイトル、発売元、発売年、地域・型番、ジャンル、読者レース順位・スコア、メモを対象に検索
- ジャンルと発売年のドロップダウンを組み合わせて絞り込み
- リスト表示では列見出しをクリックしてソート（もう一度クリックで昇順・降順を切り替え）
- 「表示列...」から一覧に表示する項目を選択。設定は次回起動時も保持
- 作品を選択すると下部にメモを表示
- 「削除」または Delete キーで選択中の作品を削除
- Ctrl+N で追加、Ctrl+F で検索欄に移動
- 「CSVテンプレート」で入力用CSVを保存し、「CSV一括登録」から読み込み。一括登録では全行を確認し、入力エラーがある場合は登録せず行番号を表示

CSVの見出しはテンプレートの日本語名または `title`, `title_en`, `publisher`, `release_year`, `region`, `genre`, `reader_race_rank`, `reader_race_score`, `image_path`, `notes` を使用できます。画像パスは絶対パス、またはCSVファイルからの相対パスを指定します。UTF-8（BOM付き）とWindowsの日本語CSV（CP932）を読み込めます。テンプレートには記入例が1行あるため、実データを入力するときはその行を置き換えてください。

CSVの `genre` は上記17区分のいずれかを指定してください。

データはこのフォルダの `games.db` に保存されます。バックアップする場合はアプリを閉じてからこのファイルをコピーしてください。
